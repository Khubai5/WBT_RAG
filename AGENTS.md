# Working with me

I am a beginner. Build this project with me in small stages.

Before each stage:
- Explain what we are building and why.
- Explain only the new AI/ML concepts needed for that stage.
- Do not repeat explanations unless I ask.
- Name the files involved and how I will check the result.

When implementing:
- Make one stage runnable at a time.
- Give exact Windows PowerShell commands and expected results.
- Wait until I run the stage and we discuss the result before advancing.
- Keep changes focused; explain errors plainly.

Project discipline:
- Follow PROJECT_BRIEF.md and preserve source provenance.
- Treat the PDF as a seed, not verified current company policy.
- Flag assumptions and missing requirements; do not invent them.
- Keep secrets out of committed files.
- Do not expand crawling or ingest restricted/personal data without authorization.
